# Seller Central pages with no API route

Some Seller Central data never comes through the Selling Partner API (SP-API). Either the page has no API route at all, or an API has it but no page in this pack covers it. Don't look for the first kind in report files: for a screen-only page, the seller reads it in Seller Central.

"No API route found" comes from research in October 2026 that checked Amazon's full API list, every report type, the notification types and the 2025-2026 release notes. That shows no route was found, not that none exists. Menu paths were checked in Seller Central UK on 28 Oct 2026. They are given for the new Seller Central's ☰ menu, or its **Site map** link where a page isn't in the menu, with the classic menu path where it helps ([seller-central-map](seller-central-map.md) has all three). Paths the check didn't reach come from Amazon's UK help pages; where a help page names only the page, not the menu, the path is marked "not confirmed".

## In an API, but not covered by a page in this pack

These have an API route, but no report page in this pack describes them. Roles marked "Restricted" need Amazon's extra review and unlock personal data: see [getting-access](getting-access.md).

| Data | API route | Role it needs |
|---|---|---|
| Balances and reserves (available, reserved, deferred) | Finances `listBalances` | Finance and Accounting ([Amazon](https://developer-docs.amazon/sp-api/docs/role-mappings)) |
| Payouts and expected payouts | Transfers `listPayouts`, `listExpectedPayouts` | Finance and Accounting ([Amazon](https://developer-docs.amazon/sp-api/docs/role-mappings)) |
| Gating per ASIN | Listings Restrictions `getListingsRestrictions` ([Amazon](https://developer-docs.amazon/sp-api/docs/listings-restrictions-api)) | Product Listing ([Amazon](https://developer-docs.amazon/sp-api/docs/role-mappings)) |
| Issues per listing | Listings Items `getListingsItem` with `includedData=issues`, one SKU per call ([Amazon](https://developer-docs.amazon/sp-api/reference/getlistingsitem)), or `searchListingsItems` with the same `includedData=issues`: up to 20 SKUs a page and 1,000 in all, and it can keep only listings with issues (`withIssueSeverity`) ([Amazon](https://developer-docs.amazon/sp-api/reference/searchlistingsitems)). Each issue has a message, a severity and any enforcement action, such as `LISTING_SUPPRESSED` or `CATALOG_ITEM_REMOVED`. Amazon's sample includes a "Restricted Products Policy Violation". Asking for `summaries` in the same call can give the listing's ASIN (an optional field). Amazon doesn't say every Account Health item shows here, so it doesn't replace that page. | Inventory and Order Tracking or Product Listing, for both ([Amazon](https://developer-docs.amazon/sp-api/docs/role-mappings)) |
| Promotions, deals and coupons | Promotions `searchPromotions`, `getPromotion` | Pricing or Product Listing ([Amazon](https://developer-docs.amazon/sp-api/docs/role-mappings)) |
| Promotion and coupon performance | `GET_PROMOTION_PERFORMANCE_REPORT`, `GET_COUPON_PERFORMANCE_REPORT` | Promotions: Selling Partner Insights or Brand Analytics (Amazon's report page says sellers use Selling Partner Insights). Coupons: Brand Analytics only ([Amazon](https://developer-docs.amazon/sp-api/docs/report-type-values-performance), [role mappings](https://developer-docs.amazon/sp-api/docs/role-mappings-for-types)) |
| Review topics per ASIN | Customer Feedback `getItemReviewTopics` | Brand Analytics or Selling Partner Insights ([Amazon](https://developer-docs.amazon/sp-api/docs/role-mappings)) |
| VAT reports | `SC_VAT_TAX_REPORT`, `GET_VAT_TRANSACTION_DATA` | Tax Invoicing (Restricted) ([Amazon](https://developer-docs.amazon/sp-api/docs/report-type-values-tax)) |
| Seller Support cases | Support API `listCases`, `getCase` | Selling Partner Support (Restricted) ([Amazon](https://developer-docs.amazon/sp-api/docs/role-mappings)) |
| Referral fee preview per SKU | `GET_REFERRAL_FEE_PREVIEW_REPORT`. Amazon refuses a request naming stores in different countries ("All provided marketplaces for this report type must be based in the same country"), so ask one store at a time; asked that way in October 2026 it was slow to build, and some stores' requests came back cancelled. For referral fees use `estimated-referral-fee-per-unit` in [fba_fee_preview](fba_fee_preview.md) (mostly SKUs with stock at Amazon, and not every one of them), and [seller_economics](seller_economics.md) for the fees actually charged. | Finance and Accounting ([Amazon](https://developer-docs.amazon/sp-api/docs/role-mappings-for-types)) |
| Page views per ASIN per day | `MARKETPLACE_ASIN_PAGE_VIEW_METRICS`. It needs a product type per request, covers only the EU-8, UK and Ireland stores ([Amazon](https://developer-docs.amazon/sp-api/docs/report-type-values-regulatory-compliance)) and reaches back 7 days. [sales_and_traffic](sales_and_traffic.md) (per child ASIN per month) and [seller_analytics_asin](seller_analytics_asin.md) (per ASIN per store per month) have page views per ASIN; [seller_analytics](seller_analytics.md) has them per store only. | Selling Partner Insights |
| Live prices and competing offers | Product Pricing v0 `getItemOffers`, `getPricing`, `getCompetitivePricing`; v2022-05-01 `getCompetitiveSummary`, `getFeaturedOfferExpectedPriceBatch` | v0: Pricing or Product Listing. v2022-05-01: Pricing ([Amazon](https://developer-docs.amazon/sp-api/docs/role-mappings)) |
| Advertising campaigns and reports | The Amazon Ads API, separate from the SP-API, with its own sign-up and agreements. Ad charges do show in this pack's reports: `ProductAdsPayment` lines in [transactions](transactions.md) and `ads[]` in [seller_economics](seller_economics.md). | Not an SP-API role. |

[report-catalogue](report-catalogue.md) lists every other SP-API route and report type.
